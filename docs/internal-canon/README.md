# Internal Canon Docs

This folder stores versioned internal product/engineering docs.

Current canonical docs:

- `EXECUTION_CANON.md` - current source of truth for AI extraction, catalog context, search execution and Telegram entry tracking.
- `AI_TESTING_GUIDE.md` - manual/live testing scenarios for AI search behavior.
- `RELEASE_CHECKLIST.md` - short deployment and smoke checklist.
- `REQUEST_CRM_STATISTICS.md` - plan and current scope for request/statistics/client CRM features.

Rules:

- Keep only documents that describe current behavior or accepted roadmap.
- Do not keep temporary audits, one-off pre-market investigations or obsolete seed review files here.
- Root-level copies are intentionally ignored via `.gitignore`.
